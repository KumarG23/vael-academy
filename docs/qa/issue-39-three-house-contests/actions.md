# Curated real-input battle actions

Start from the corresponding saved UI payload listed in `results.json`. The five fixture-route payloads resume in round 3 after the two recorded AI phases and the first player exchange; the native Thornrook opening starts in round 1. These are input-earned saves on the declared accepted source. No board/outcome editing is needed.

For each row: select the actor at **From** with arrows/pointer and Return; confirm **To** through movement; choose Attack/Magic and the current weapon if a selector opens, then confirm **Target**. A dash means choose Wait. Return advances ordinary quotes/level-up overlays. At a round boundary use **T → End Turn** if the phase did not advance automatically. The rows are tactical choices, not direct handler calls. Kai is held back in the later completed runs; unacted allies are allowed by the normal End Turn confirmation.

Fresh-entry/input sampling before these saves is described in the README: Title load, Mission Board deployment, preparations, two T → End Turn phases, player forecast/strike, field-menu save, fresh-process Title load and a second save.
