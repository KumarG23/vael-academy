# CP-9 practice cues

Original local synthesis: cue tick, metal block and dodge air sweep. No
third-party samples, service calls, account use or spend. No additional
third-party attribution requirements. `generate.py` reuses CP-8's deterministic
48kHz mono PCM16 writer; run with Python standard library only. It writes only
the three defense WAVs and preserves all CP-8 files. Playback uses AudioManager
and its existing volume/mute controls. Existing FX/art licenses remain in
`assets/source/hybrid_combat_fx/README.md` and the stage credit footer.
